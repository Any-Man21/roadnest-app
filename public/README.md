
# RoadNest – Car Rental Platform

**RoadNest** is a modern car rental platform designed to make discovering, listing, and booking rental vehicles simple and convenient. Users can explore available cars, view detailed vehicle information, and manage their bookings through a clean and responsive interface.

🌐 **Live Website:** [Visit RoadNest](https://roadnest-app.vercel.app)

---

## ✨ Features

- **Explore Cars:** Browse a collection of rental vehicles with detailed information, including images, rental prices, categories, seating capacity, and locations.
- **Smart Car Search:** Find vehicles easily using search functionality and category-based filtering.
- **Detailed Car Pages:** View individual vehicle details, descriptions, availability status, and rental information.
- **User Authentication:** Secure user authentication and session management powered by Better Auth.
- **Car Listing:** Authenticated users can add their own vehicles to the platform by providing essential car information.
- **Booking Management:** Create, view, and manage car rental bookings through dedicated booking pages.
- **Order Management:** Track rental orders and view relevant booking information through an organized interface.
- **Owner Information:** Display vehicle ownership details to provide better transparency between users and renters.
- **Responsive Design:** Enjoy a consistent browsing experience across desktop, tablet, and mobile devices.
- **Modern UI:** A dark-themed interface with smooth animations, interactive components, and polished visual elements.

## 🚀 Getting Started

Follow these steps to run the frontend locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd RoadNest
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root and configure the required environment variables.

```env
NEXT_PUBLIC_API_URL=YOUR_BACKEND_API_URL
```

Configure any additional authentication or database-related environment variables required by your project.

### 5. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
